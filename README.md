# Broken Link Checker and HTTP Status Code Auditor

[![Broken Link Checker](https://img.shields.io/badge/TAVARDT-Broken%20Links-5b3cf5.svg)](https://tools.tavardt.com/au/broken-link-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Systematic crawling and validation of internal links, external citations, and response status codes.

Developed and maintained by the digital systems and crawl standards group at **TAVARDT Australia**.

***

## Link Auditing and 404 Detection

* **Systematic Hyperlink Verification**: Parsing and validating internal paths and outbound links.
* **HTTP 404 and Server Failure Alerts**: Immediate reporting of defective URLs and server disruptions.
* **Crawl Efficiency Preservation**: Preventing search engine spiders from encountering dead ends.
* **Anchor Text Integrity**: Assessing anchor clarity against modern web usability benchmarks.
* **Link Quality Score**: Benchmark score from 0 to 100 with clear defect prioritisation.

***

## Installation and Usage

Compatible with Python 3.8+ without additional packages.

```bash
git clone https://github.com/TAVARDT-Australia/broken-links-checker-au.git
cd broken-links-checker-au
python broken_links_scanner.py https://enterprise.com.au
```

Run with structured JSON output:

```bash
python broken_links_scanner.py https://enterprise.com.au -json
```
